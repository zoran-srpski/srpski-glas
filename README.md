# Српски глас

Језгро Android прототипа које претвара Google-ов српски говорни унос са
латинице на српску ћирилицу. Обрађује недвосмислене говорне команде за
интерпункцију (`знак тачка`, `знак зарез`, `знак упитник`, `знак узвичник`)
и познате
правописне изузетке (`инјекција`, `конјункција`, `надживети`).

Почетни Android прототип садржи дугме за диктирање, приказ ћириличног резултата
и копирање текста. Апликација не чува и не шаље диктирани текст на сопствени
сервер; користи системско Google препознавање говора које је већ инсталирано
на Android телефону.

## Говорне команде

- `знак тачка` → `.`
- `знак зарез` → `,`
- `знак упитник` → `?`
- `знак узвичник` → `!`
- `команда нови ред` → прелазак у нови ред

Обичне речи остају непромењене: „тачка ослонца“ и „децимални зарез“ не постају
знакови интерпункције.

## APK

GitHub Actions аутоматски гради пробни APK после сваке измене главне гране.
Резултат се преузима са странице **Actions → Build Android APK → Artifacts**.
